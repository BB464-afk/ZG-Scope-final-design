# Public Assets Folder

This folder contains static assets that are served directly by the web server.

## Logo Files Required

Please place the following logo files in this `/public` folder:

1. **ZGP_Logo_vivid_orange.png** - Full Zauner Group logo (used in expanded sidebar and login screen)
2. **ZGP_Signet_vivid_orange.png** - Zauner Group signet icon (used in collapsed sidebar)

## How to Add the Logos

1. Copy `ZGP_Logo_vivid_orange.png` from the root directory to `/public/ZGP_Logo_vivid_orange.png`
2. Copy `ZGP_Signet_vivid_orange.png` from the root directory to `/public/ZGP_Signet_vivid_orange.png`

Once copied, the logos will render properly on any PC.
